# 📦 택배 물류 관리 시스템 (Java)  
> 교내 프로젝트 (2023.05 ~ 2023.06) <br>
> 🏅 교내 오픈소스 활용 창의 SW경진대회 독행상 수상

---

## 📌 프로젝트 소개
택배 배송 과정에서 사용자와 관리자 역할을 분리하여  
배송 상태를 효율적으로 관리할 수 있도록 설계한 물류 관리 시스템입니다.

---

## 🚀 주요 기능

### 👤 사용자 기능
- 회원가입 및 배송지 입력  
- 로그인 기반 상품 조회 기능  

### 🏢 관리자(권리자) 기능
- 중간 경유지 설정  
- 배송 위치 변경 및 상태 관리  

---

## ⚙️ Tech Stack
- Language: Java (GUI)  
- Database: MySQL  
- API: Google Maps API  

---

## 💡 개발 환경 제약
Java 기반 수업 환경에서 프로젝트를 수행하며  
GUI, 로직을 모두 Java로 직접 구현하고  
Google Maps API를 연동하여 위치 기반 기능을 확장했습니다.

---

## 💡 배운 점
- 사용자와 관리자 권한 분리 설계의 중요성 이해  
- GUI 기반 애플리케이션에서 데이터 흐름 관리 경험  
- 외부 API(Google Maps) 연동을 통한 기능 확장 경험
